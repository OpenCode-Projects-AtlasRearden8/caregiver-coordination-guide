# Start Here

**The Caregiver Coordination Guide** is a plain-English manual for organizing the care of an
aging or ill loved one. It is the companion to the *Health Admin Kit* (which covers **your own**
paperwork). This guide covers **theirs**: doctors, medications, documents, siblings, updates,
and taking care of yourself while you do it.

> **Coordination help, never medical advice.** This guide explains how to organize appointments,
> papers, and people. It does not tell you what medicine to give, what treatment to choose, or
> what any diagnosis means. For anything medical, ask your loved one's doctor or care team.
> See [the full disclaimer](disclaimer.md).

Nothing here requires an app, an account, or the internet beyond the first copy. Everything is
printable, fillable by hand, and yours to copy as many times as you need.

## The one-page version

If you only read one paragraph this week, here it is:

1. **Find the papers.** Start the [Document Grab-List](02-document-grab-list.md) today. It unlocks everything else.
2. **Make the calls.** Work the [First-Calls Checklist](01-first-calls-checklist.md) top to bottom.
3. **Write things down.** A [med log](03-med-logs.md) and a [doctor log](04-doctor-logs.md) prevent the worst mistakes.
4. **Share the load early.** Bring siblings in with the [task-split worksheet](05-sibling-task-split.md), before resentment has a chance to harden.
5. **Send one honest update a week.** Use the [AI drafting prompts](06-ai-weekly-updates.md) and save ten minutes and several arguments.
6. **Protect the caregiver.** Schedule [respite](07-respite-and-guilt.md) like it is a prescription, because functionally it is.

## How to use this folder

- Read the markdown chapters in `docs/` for the how-to.
- Print the blank worksheets in `worksheets/` (see [Worksheets](08-worksheets.md));
  print several copies. Logs work best on a clipboard near the meds.
- Prefer paper? Everything works with a three-ring binder.
- Prefer digital? The same worksheets work in any notes app; just keep one **single** copy
  of truth. Two half-updated logs are worse than one sloppy log.

*This guide is for organizing logistics. It is never a substitute for medical advice, diagnosis,
or treatment. When in doubt, call the care team.*
